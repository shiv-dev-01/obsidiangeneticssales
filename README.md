# Obsidian Genetics Sales

Sales site for **Obsidian Genetics**.

The repository name is `obsidiangeneticssales` because this project is the sales code for Obsidian Genetics.

## Stack

- React
- Vite
- React Router
- Axios
- Tailwind CSS
- React Hot Toast
- TypeScript

## Requirements

- Node.js 18 or later
- npm

## Run locally

```bash
git clone https://github.com/shiv-dev-01/obsidiangeneticssales.git
cd obsidiangeneticssales
npm install
npm run dev
```

The dev server opens at http://localhost:5173.

## Scripts

| Command | What it runs |
| --- | --- |
| `npm run dev` | `vite` |
| `npm run build` | `vite build` |
| `npm run lint` | `eslint .` |
| `npm run preview` | `vite preview` |
